# 요구사항 분석 초안

## 1. 프로젝트 주제

가격대와 메뉴 선호도 기반 식당 추천 서비스

## 2. 문제 정의

사용자는 식당을 선택할 때 예산, 메뉴, 식사 목적 등을 함께 고려해야 한다.
이 과정에서 여러 후보를 직접 비교해야 하므로 선택이 번거롭고 시간이 오래 걸린다.

## 3. 주요 사용자

| 사용자 | 설명 |
|---|---|
| 대학생 | 제한된 예산 안에서 식당을 찾고 싶은 사용자 |
| 직장인 | 빠르게 점심 또는 저녁 식당을 정하고 싶은 사용자 |
| 혼밥 사용자 | 혼자 방문하기 좋은 식당을 찾고 싶은 사용자 |
| 데이트/친구 식사 사용자 | 식사 목적에 맞는 식당을 찾고 싶은 사용자 |

## 4. 기능 요구사항 초안

| ID | 기능 요구사항 |
|---|---|
| FR-01 | 사용자는 예산을 입력할 수 있어야 한다. |
| FR-02 | 사용자는 음식 카테고리를 선택할 수 있어야 한다. |
| FR-03 | 시스템은 입력 조건에 맞는 식당을 추천해야 한다. |
| FR-04 | 시스템은 각 추천 결과에 대해 추천 이유를 표시해야 한다. |
| FR-05 | 조건에 맞는 식당이 없을 경우 안내 메시지를 표시해야 한다. |

## 5. 비기능 요구사항 초안

| ID | 비기능 요구사항 |
|---|---|
| NFR-01 | 사용자는 추천 조건 입력 후 빠르게 결과를 확인할 수 있어야 한다. |
| NFR-02 | 추천 이유는 사용자가 이해할 수 있는 문장으로 제공되어야 한다. |
| NFR-03 | 잘못된 입력값에 대해 안내 메시지를 제공해야 한다. |
| NFR-04 | 식당 데이터는 수정과 추가가 쉽도록 JSON 또는 CSV 형태로 관리한다. |
| NFR-05 | 추천 로직은 추후 조건 추가가 가능하도록 유지보수하기 쉽게 작성한다. |

## 6. MVP 범위

### 포함 기능

- 예산 기반 추천
- 메뉴 카테고리 기반 추천
- 식사 목적 기반 추천
- 추천 이유 표시
- 조건 불일치 안내

### 제외 기능

- 지도 API
- 로그인/회원가입
- 리뷰 크롤링
- 실제 AI 모델
- 실시간 위치 기반 추천
- 데이터베이스 연동

## 7. 기술 스택

본 프로젝트는 빠른 MVP 구현을 위해 React + Vite 기반의 프론트엔드 중심 구조로 개발한다.

| 구분              | 내용               |
| --------------- | ---------------- |
| Frontend        | React + Vite     |
| Language        | JavaScript       |
| Data            | restaurants.json |
| Style           | CSS              |
| Test            | 추천 로직 함수 단위 테스트  |
| Version Control | GitHub           |

별도의 백엔드 서버나 데이터베이스는 사용하지 않는다.
식당 데이터는 `restaurants.json` 파일에 저장하고, 화면에서 사용자가 입력한 조건을 바탕으로 추천 로직을 수행한다.

이 방식은 구현 범위를 줄일 수 있고, 추천 로직과 화면을 분리하여 테스트하기 쉽다는 장점이 있다.
