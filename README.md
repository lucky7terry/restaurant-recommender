# restaurant-recommender
가격대와 메뉴 선호도 기반 식당 추천 서비스

## 프로젝트 소개

사용자가 예산, 음식 카테고리, 식사 목적을 입력하면 조건에 맞는 식당을 추천하고 추천 이유를 제공하는 웹 기반 식당 추천 서비스입니다.

## 문제 정의

식당을 선택할 때 사용자는 예산, 음식 종류, 식사 목적 등을 함께 고려해야 합니다.
하지만 여러 조건을 직접 비교하며 식당을 고르는 과정은 번거롭고 시간이 오래 걸립니다.
본 프로젝트는 간단한 조건 입력만으로 적합한 식당을 추천하여 식당 선택 과정을 줄이는 것을 목표로 합니다.

## 주요 사용자

- 대학생
- 직장인
- 혼밥 사용자
- 데이트 또는 친구 식사 사용자

## MVP 기능

- 예산 입력
- 음식 카테고리 선택
- 조건 기반 식당 추천
- 조건에 맞는 식당이 없을 경우 안내 메시지 표시

## 제외 기능

- 지도 API
- 로그인/회원가입
- 리뷰 크롤링
- 실제 AI 모델
- 실시간 위치 기반 추천
- 데이터베이스 연동
